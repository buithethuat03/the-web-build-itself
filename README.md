# Thuật Bùi — Interactive Portfolio & CV

An interactive, cinematic portfolio that constructs itself in real time with synchronized typing and mechanical audio.

## ✨ Features

- **Dual Modes**: Direct portfolio view or real-time cinematic build story.
- **Interactive CV**: Experience, projects, skills, and contact info for Bùi Thế Thuật.
- **Audio & Visuals**: Web Audio mechanical typing sound and 60 FPS live preview.

## 🚀 Quickstart

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```

## 🛠 Tech Stack

React 18 · TypeScript · Vite · Tailwind CSS 4 · Web Audio API
