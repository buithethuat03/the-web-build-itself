# The Web Builds Itself (1991 → 2026)

> **An authored, browser-native cinematic performance celebrating the evolution of HTML, CSS, and JavaScript.**

From a solitary, stark black-and-white `Hello, World!` at CERN in 1991 to a living, reactive modern application runtime in 2026—watch the World Wide Web construct itself line by line in real time.

---

## 🌐 The Historical Journey

- **1991 · The Spark: Hello World**: Tim Berners-Lee at CERN invents the World Wide Web. Plain unstyled document on the Line-Mode browser.
- **1993 · Hypertext & Anchors**: The birth of the `<a>` tag, blue underlined links (`#0000ee`), and the Mosaic browser.
- **1996 · The Wild 90s: Tables & Chaos**: Before CSS, designers hacked layouts using nested `<table>` tags, colorful cells, `<marquee>` banners, and retro visitor counters.
- **2001 · The CSS Revolution: Zen Garden**: Separation of concerns. Live CSS strips the 90s table hacks and reveals clean editorial typography.
- **2008 · HTML5: Semantic Awakening**: Goodbye Flash. Native `<header>`, `<article>`, `<canvas>`, and GPU-accelerated web computing.
- **2015 · Flexbox & Grid: Fluid Layouts**: Modern responsive geometry adapting fluidly across phone, tablet, and desktop viewports.
- **1995-2015 · JavaScript: The Living DOM**: Created in 10 days, JavaScript transforms static markup into living software.
- **2024 · Reactive Canvas & Micro-Interactions**: Generative 60 FPS particle background and real-time era theme switching (`1991 CERN`, `2001 Zen`, `2026 Neo-Glass`).
- **2026 · The Living Web Platform**: Full-stage modern web application with micro-interactions, dark obsidian glassmorphism, and live state synchronization.

---

## ⚡ Technical Highlights

- **Dual-Pane Cinematic Engine**: Left pane streams authentic, syntax-highlighted code; right pane renders the sandboxed document at 60 FPS with zero iframe reloads.
- **Real Mechanical Keyboard Audio**: Integrated with 24 authentic studio switch recordings (Mechvibes Classic Soundpack) + dedicated Enter/Spacebar samples. Progressive loading ensures instant audio actuation.
- **Generative Polyphonic Synth Score**: 100% native Web Audio API ambient soundtrack that evolves harmonically with each historical era.
- **Deterministic Timeline Scrubber**: Any millisecond timestamp $t \to \text{DOM state}$. Jump between chapters, scrub smoothly, or switch speeds (`0.5x`, `1x`, `2x`, `5x`, `10x`).
- **Mobile & Desktop Responsive**: Fully adaptive responsive layouts with specialized segmented tabs for mobile screens.

## 🚀 Quickstart

```bash
# Clone the repository
git clone https://github.com/buithethuat03/the-web-build-itself.git
cd the-web-build-itself

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
